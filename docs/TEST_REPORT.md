## 誤検知評価の実施結果

`aisecure evaluate` を同梱の合成シナリオ4件（40ユーザー×5日、合計18.84日・85,509イベント）に対して実行しました。出力は `docs/evaluation/` に含めています。

| 設定 | 検知 | 誤検知 | 検知漏れ | 誤検知/日 |
|---|---|---|---|---|
| 既定 | 3 | 111 | 0 / 3 | 5.89 |
| `identity_conditions: both` | 3 | 102 | 0 / 3 | 5.41 |

ルール別では AS-003（単体の大量参照）が103件中102件の誤検知、AS-004（相関）は誤検知0件でした。閾値スイープ21通りの結果、誤検知が0になる設定ではラベル付き事案も検知できませんでした。判断と限界は `docs/TUNING.md` を参照してください。

**これは合成データに対する測定です。実環境の誤検知率ではありません。** 正常側に含めたのはバックアップ、分析作業、移行作業、承認済み保守接続のみで、事案側は1パターンだけです。

## 取り込みの実施結果

`examples/make-example-logs.py` が生成した合成ログ（資産CSV 4行、認証CSV 9行、ファイル参照JSONL 1,835行）を `aisecure import` で取り込み、読み飛ばし0行、出所ハッシュ3件を記録し、続く `analyze` で AS-001 / AS-002 / AS-003 / AS-004 を検知することを確認しました。JST無表記時刻のUTC変換、epoch millisの解釈、機密ラベルの三値判定を含みます。

実VPN機器、Okta組織、その他のIdP、実ファイルサーバーの出力形式では未検証です。Oktaアダプターと直接監視はローカルモックでのみ確認しています。署名付き承認は外部SSO/RBACゲートウェイの証明書式を検証する境界までで、実組織のログイン・RBAC・鍵管理は未検証です。監査チェックポイントも外部受信先のWORM保管までは含みません。文字コード（cp932等）の実データ、巨大ファイル、ローテーション途中のファイル、圧縮ログも未検証です。

## ブラウザ表示の確認

v0.1と同じ範囲です。Chromium + Playwrightによる **オフラインのDOM描画** で確認しました。実行環境の管理ブラウザはlocalhostへの直接ナビゲーションを `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否したため、その制限は変更せず、同じHTML/CSS/JSに読み取り専用の合成状態を埋め込んで表示を検証しました。HTTP APIは、別途上記テストで本物のローカルHTTPサーバーを起動して確認しています。

確認できた範囲:

- デスクトップ 1512×1080 の概要表示と全体スクリーンショット。
- スマートフォン幅 390×844 で横方向のはみ出しがないこと。実iPhone/Safariでの試験ではありません。
- 概要、資産、計画、監査、設計の各画面の切り替え。
- 読み取り専用プレビューでは書き込みボタンを無効化。
- 上記範囲でJavaScriptの実行時エラーなし。

v0.2では、`tools/dom-check.mjs` で概要・資産・計画・**検知設定**・監査・設計の6画面を Node 上の最小DOMで実行し、実行時エラーがないこと、各画面が空にならないこと、検知設定画面に閾値項目・`identity_conditions`・測定手順・設定ハッシュが出ることを確認しました。**これは「JavaScriptが落ちない」ことの確認であり、ブラウザでの描画・レイアウト・CSSの検証ではありません。** 使用しているDOM実装はこのチェック専用の簡易版です。

**v0.2で追加した「検知設定」画面は、実ブラウザでの描画・レイアウトが未確認です。** また、本番と同じブラウザ通信経路でのE2E試験、CSPと実画面操作を一体にしたE2E試験、Safari・Firefox・Windows・macOSでの動作も未検証です。スクリーンショットは同梱の `docs/screenshots/` を参照してください（v0.1時点の画面で、検知設定画面は含まれていません）。

## 未検証・未測定

実VPN、Okta組織、その他のIdP、ファイルサーバー、SSOで認証された複数管理者、マルチテナント、実機の停止・失効・復旧、大規模ログ、長期運用、侵害されたホスト、外部監査保管、保持期限・削除ポリシーは未検証または未実装です。Oktaアダプター、署名付きWebhook、外部SSO/RBAC署名証明、暗号化保管、監査チェックポイントはローカルテストで境界を検証したもので、実組織・外部鍵管理・WORM受信先・プロバイダーの実環境で安全に遮断できることを証明していません。

合成シナリオで条件が正しく動くことと、現実の侵害を検出できることは異なります。実環境の検知率、誤検知率、初動時間短縮、漏えい防止の効果、セキュリティ認証取得を確認したものではありません。出荷や顧客導入には `SECURITY.md` の本番化ゲートが必要です。
