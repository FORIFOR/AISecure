# 実動作動画 — 絵コンテと収録手順

最終更新: 2026-09-22。対象: `aisecure.control` 0.4.0a3.dev0 のデモモード。

**この動画は実アプリの画面収録である。** モック画面、生成映像、再現アニメーションは
使っていない。収録スクリプトは `tools/record_demo.cjs` で、実際のローカルサーバーを
起動し、実際の Scanner に検査させ、実際に出た判定を撮っている。

## 絵コンテ

時系列どおりに撮る。並べ替えはしない。

| 時間 | 画面 | 字幕（無音で読める） |
|---|---|---|
| 0.0–3.0s | 「社外秘」を含む本文が入力欄にある状態 | 社外秘の資料を、AIに貼ろうとしている |
| 3.0–8.0s | 本文を実際に入力していく | 送る前に、この端末だけで検査する |
| 8.0–13.0s | 「送信せずに検査」を押す → 検査中 | APIキーも外部送信もなし |
| 13.0–22.0s | 判定カードが出る（保留・DOC-CLASS・根拠・検査範囲） | 保留。理由と検査範囲まで出る |
| 22.0–28.0s | 「検査結果をJSONで保存」→ 保存されたJSON | 判定は手元にJSONで残る |
| 28.0–31.0s | 起動コマンド3行 | 3分で試せる |

尺: サイト用 16:9 で28–32秒、X用 9:16 で18–24秒。同じ収録から編集する。

## 撮ってはいけないもの

- 実在の機密、個人情報、トークン、実在の宛先。入力は合成サンプルのみ。
- 起動URLに含まれるトークン（`#token=` 以降）。収録前にhashを除去する。
- 実運用を装った成功例。デモモードであることを字幕に出す。

## 編集で禁止すること

- 検査時間の短縮・早送りによる高速化の演出。実時間のまま出す。
  待ち時間を詰めた場合は画面に明示する。
- 判定の差し替え、検出件数の加工、未実装機能の合成。
- 9:16 を 16:9 の中央切り抜きで作ること。UIと字幕を再配置する。

## 再現手順

```sh
# 1. 収録（実サーバーを起動し、実際の検査を撮る）
NODE_PATH=<playwright> node tools/record_demo.cjs docs/media/demo-raw

# 2. 編集（16:9 と 9:16 を同じ素材から書き出す）
python -m tools.build_demo_video docs/media/demo-raw docs/media
```

出力:
- `docs/media/demo-desktop.mp4` … サイト埋め込み用 16:9
- `docs/media/demo-vertical.mp4` … X用 9:16
- `docs/media/demo-poster.jpg` … poster画像
- 元録画は `docs/media/demo-raw/` に残す。

## 既知の制約

- 収録環境は macOS / Chromium。Windows と Safari での見え方は未確認。
- 字幕は焼き込み。スクリーンリーダー向けには本文側で同じ内容を提供する。
- 音声なし。自動再生しない。`poster` を置き、利用者の操作で再生する。
