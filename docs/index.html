GOOD QUESTIONS

Before you begin.

Does installation protect my device or VPN?

No. The preflight library must be integrated into a mandatory pre-send path. This version does not monitor a whole device, patch VPNs or isolate a network automatically.

Does generative AI decide what is safe?

Rules make the decisions. Optional local AI writes supplementary explanations from minimised facts and reference IDs. Reference-ID consistency is checked, not the truth of generated prose. The new guard is not automatically connected to the existing dashboard.

Does it detect every secret or attack?

No. It uses limited text patterns and trusted classification labels. Names-only lists, custom secrets, attachments, images, encrypted or split data are not comprehensively covered. This is not a general prompt-injection detector.

Does this homepage send information out?

This homepage does not send interaction analytics. Loading pages, images and video still involves the hosting service. An inquiry is sent to the existing contact service only after you consent and submit the form. There is no real-data diagnostic input here.
