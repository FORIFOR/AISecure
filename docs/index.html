IMPLEMENTATION STATUS

What works.
What still needs connecting.

Implemented code is not the same as active protection in your environment. Here is the current boundary for each capability.

Implemented / integration required

AI-bound text checks

Refuse unapproved destinations, confidential classifications and some secret patterns. Your adapter must enforce the guarded path.

Implemented / submitted history only

Historical action review

Re-check JSON action history through the CLI. No automatic browser-history collection or proof of delivery or a leak.

Implemented / observed scope only

Log import and correlation

Import CSV and JSONL, watch local exports, and connect the supplied asset, authentication and file-access records.

Optional / explanation only

Local AI explanations

Rules and templates are the default. An optional Ollama model assists with wording, without decision or execution authority.

Limited connection / E2E unverified

Okta logs and session response

System Log retrieval and a two-person-approved session-revocation path exist. End-to-end testing in a real organisation is still outstanding.

Not implemented / production requirement

Endpoint DLP and VPN controls

Device-wide DLP and direct VPN inventory, vulnerability matching, patching and isolation require separate integrations and testing.

Zero findings does not mean the whole environment is safe. Unconnected paths, images, PDFs, attachments, encoded data and split payloads are outside this text guard’s coverage.

PREVENTION REQUIREMENTS

Different risks. Different control points.

Data removal and VPN-based intrusion need different controls. This version has not demonstrated prevention of either incident class.

Preventing data removal

A legitimate account should not be enough to send confidential data to personal storage. Test small transfers and single-file exports, too.

Required integrations: endpoint DLP, corporate versus personal tenant identity, and non-bypassable outbound controls.

Reducing VPN intrusion risk

Consider exposure, privilege and access to sensitive data, not just severity scores. Connect prioritisation to temporary restrictions and device-level verification.

Required integrations: real device inventory, version and vulnerability matching, approved containment and recovery.

QUESTIONS & BOUNDARIES

Before you deploy.

Does installation protect my device or VPN?

No. The preflight library must be integrated into a mandatory pre-send path. This version does not monitor a whole device, patch VPNs or isolate a network automatically.

Does generative AI decide what is safe?

Rules make the decisions. Optional local AI writes supplementary explanations from minimised facts and reference IDs. Reference-ID consistency is checked, not the truth of generated prose. The new guard is not automatically connected to the existing dashboard.

Does it detect every secret or attack?

No. It uses limited text patterns and trusted classification labels. Names-only lists, custom secrets, attachments, images, encrypted or split data are not comprehensively covered. This is not a general prompt-injection detector.

Does this homepage send information out?

This homepage does not send interaction analytics. Loading pages, images and video still involves the hosting service. An inquiry is sent to the existing contact service only after you consent and submit the form. There is no real-data diagnostic input here.
