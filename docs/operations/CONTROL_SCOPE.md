## 検証で見つけた欠陥

この表の「ローカル試験済み」は、**一つの環境で通ったという意味しか持ちません**。
実際、当初「121件成功」と記録された control テストは、宣言依存の `pypdf>=6.19` と
macOS では 21 failures / 16 errors でした。資料検査は安全側に倒れてはいたものの、
一度も実行されていませんでした。詳細は `CONTROL_VALIDATION.json` の
`defects_found_and_fixed_during_verification` にあります。

CIが ubuntu-latest しか見ていなかったことが原因なので、マトリクスに macOS と
Python 3.14 を追加しました。**検証環境を一つしか持たないことは、それ自体が欠陥です。**

## 絶対に表示しない完了表現

- 全PC・全AI・全VPNを保護済み
- 拡張機能が警告したため、外部へ届いていない
- acceptルールをdisableにしたため、VPN侵入を防いだ
- 未検出のため、機密情報が存在しない
- 合成テストで成功したため、企業の本番でも安全
- フラグがtrueのため、実機検証済み
