## 本番未検証の主要項目

`validation.example.json` は既定で全項目 `not_run` です。形式チェックだけで防御成功を捏造しません。
外部条件が必要な項目に、実際にない機器名・組織・APIキー・レビュー担当者を補って完了扱いにはしません。
本番向けVPN/DLPアダプターとSSO統合には、接続対象を定めた追加実装が残っています。

本リポジトリの自動試験と、実機/実プロジェクトの試験結果は別保管します。公開Issueに生ログ・認証情報を貼らないでください。
